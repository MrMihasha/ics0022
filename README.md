# Secure Password Manager

## Project Scope
This project is a web-based Secure Password Manager developed for the Secure Programming course. The application allows users to safely store, retrieve, and manage their credentials with a strong focus on cryptographic security, secure memory management, and authenticated encryption for data at rest.

## Planned Screens (Interface)
*   **Login/Register:** Secure authentication interface requiring a master password.
*   **Vault Dashboard:** Main view displaying a list of stored credentials (service names).
*   **Add/Edit Credential:** Interface to input a new site, username, and password to be securely encrypted and stored.

## How to Build and Run
1. Clone the repository: `git clone https://github.com/MrMihasha/ics0022/`
2. Navigate to the directory: `cd ics0022`
3. Create a virtual environment: `python3 -m venv venv`
4. Activate it: `source venv/bin/activate`
5. Install dependencies: `pip install -r requirements.txt`
6. Run the application: `flask run`
